# 📁 File Manager App

A modern Android File Manager built using **Jetpack Compose**, designed to provide a clean, fast, and intuitive way to browse, manage, and organize files on your device.

---

## 🚀 Features

- 📂 Browse internal storage directories
- 📄 View files and folders in a structured UI
- ✂️ Copy, Cut, Paste functionality
- 🗑️ Delete files and folders
- 🔍 Easy navigation between directories
- 📱 Modern Material Design UI with Jetpack Compose
- ⚡ Smooth and responsive performance

---

## 🛠️ Built With

- Kotlin
- Jetpack Compose
- Android SDK
- File System APIs
