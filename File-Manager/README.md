# 📁 File Manager App (Jetpack Compose)

A modern Android File Manager built using **Jetpack Compose**, designed to provide a fast, clean, and intuitive way to browse and manage files across internal and external storage.

---

## 🚀 Features

### 📂 File Management
- Browse **internal and external storage (all available drives)**
- Navigate through folders with smooth UI
- View file details in a structured layout

### ✂️ File Operations
- Cut files/folders
- Copy files/folders
- Paste items to any directory
- Delete files and folders safely

### 📱 Smart File Categorization
Automatically detects and categorizes files into:
- 📄 Documents (PDF, TXT, etc.)
- 🖼️ Images
- 🎥 Videos
- 🎧 Audio files

### 🎨 UI & Experience
- 🌙 Automatic **light/dark theme switching**
- ⚡ Smooth and responsive Jetpack Compose UI
- 📱 Clean Material Design interface

---

## 🛠️ Built With

- Kotlin
- Jetpack Compose
- Android SDK
- File Storage APIs
